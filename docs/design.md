## 科学与工程边界
一个 market_id 对应一个任务，首版 Yes/No。预测截止时刻固定；所有正文版本必须 published_at <= cutoff 且 observed_at <= cutoff。批次 scraped_at 只作为保守归档可用时间。ground_truth 的 price_collapsed/expired 均为代理标签，不能声称官方真值或准确率提高。模拟预算和虚拟轮次时钟显式标注，不宣称实际在线开销或真实来源永久枯竭。

新闻变为五要素必须保存出处、抽取方式、规则版本。提供人工注释导入和确定性的保守规则抽取；规则不能判定支持时为0，不把新闻正负情感或市场价格当支持度。完整通用语义理解不在无模型模式下声称实现。没有证据的任务输出均匀分布及状态。

同 URL 重复命中不重计，不重置静默；同 URL 正文版本保留，但任务时点仅选一版；增强方案跨来源相同规范化五要素按事实簇统一排序并几何折减，基础方案按实施例一分别在窗口和过渡带内排序。新闻发布时间与事实时间独立。来源用发布方/域名，provider 只是检索渠道。间隔按发布时间排序去重后重算，不能按检出顺序直接相减。

工程裁定：回收仍发起检索动作，但已读取的正文在各阶段复用缓存，只对新正文收阅读费；查询调用费仍按动作收取。预算为可解释模拟，并非实际服务商收费。来源退活跃状态只影响后续检索分配，已取得证据保留到时间窗口排除，避免把静默等同于证据失效。

## 核心公式
关联度为规范化(要素名,值)集合与目标集合交集占比。权重 gamma^(rank-1)，同发布时刻按 source_id, evidence_id 排序。支持度{-1,0,1}加权平均后 softmax(omega*z)。基础空尽 min(1,silence/(mean_interval+wait))；增强 S(x)=(count(interval>x)+alpha)/(n+alpha)，phi=S(effective+wait)/S(effective)，effective+wait<=max_interval 时再与 effective/max_interval 取min；无样本取0。覆盖1-exp(-budget/b0)。过渡带[a-W,a)，分格预算 cap*exp(-lambda*distance/W)。损失L=sum(v*r)，loss=L/(L+V)，0/0=0。增强停止 min(phi)>=threshold 且回溯所有abs(delta)<=epsilon；初始不足K轮取已有轮。收缩当轮跳过停止判定并重启确认历史。向早移动须高损失且 mu*L-cost>=0；mu上限、冷却K轮不再次触发向早移动。回收当轮重算计量和来源状态，边界下一轮用于检索。

## 实现约定
固定窗口 baseline 共享证据池、抽取、预测器和预算，只禁用动态窗口/降频/空尽停止。基础和增强使用策略配置。所有阈值是示例配置，非历史标定参数。成本包含每次空请求及逐条阅读费用，按来源预算和全轮预算双重上限；预算不够一个动作就不执行。检索游标避免重复首屏；守候已空尽来源。过渡带探测结果与窗口共享簇但不直接进入概率支持求和。

数据适配需要完整清点所有JSON结构，解析失败/类型混杂/缺时间显式统计；发布间隔只反映已观测样本，并非来源全量产出。断网无依赖运行，导出配置、证据、轮次、结果、HTML。审计与评估模块严格隔离标签。
