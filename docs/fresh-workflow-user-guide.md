# 新事件工作流使用说明

入口：http://127.0.0.1:8765/ → 任务中心 → 新事件。

1. 设置 UTC 截止时刻，选择候选数量（1–20）和每事件文档上限（12–40）；可调整窗口与模拟预算。
2. 点击“预览新事件”。服务从本地归档筛选，排除已有预测事件与已用正文/URL，执行时间、来源和覆盖门槛。这一步不调用模型。
3. 查看冻结候选、文档数量、选择规则；勾选需要运行的事件。改变截止时刻或配置会使原预览失效。
4. 点击“抽取并运行选中事件”。服务只接收预览ID和选定市场，不接受浏览器指定的文件路径或API密钥。
5. 运行记录显示实际完成文档、通过/失败数量、token用量及保存的策略结果。每个事件共享同一有效子集，生成固定、基础动态、增强动态三份结果。
6. 打开结果回放窗口、概率和五要素诊断；已有评价显示在实验对比页面。

密钥通过启动服务时的 DEEPSEEK_API_KEY 环境提供，不填写到网页、不写入配置文件、localStorage或导出。网页仅显示凭据是否已配置；这不证明密钥有效或账户余额足够。服务重启后需要重新从启动环境提供密钥。

抽取会把事件信息和每篇最多12,000字符新闻片段发送至DeepSeek，实际token与检索模拟预算分别记录；不估算账单金额。本版本每个未缓存文档只尝试一次HTTP请求，结构校验失败不会伪造成中性证据。

取消会终止当前工作进程，保留缓存、逐篇抽取记录和已验证预测；已发出的请求可能仍计费。服务重启不会自动恢复付费任务；Windows父进程句柄监测会结束失去服务父进程的抽取worker。已保存结果可继续打开。

数据目录：

- 冻结预览：.runtime/fresh-previews/<预览ID>/
- 任务进度与所选输入：.runtime/web-jobs/<任务ID>/
- 模型抽取和三策略预测：artifacts/web-semantic/<任务ID>/
- 单次返回缓存：artifacts/deepseek-cache/
- 取消前已完成文档：对应输出目录的 partial-extraction.jsonl

首次独立评价输入另存于 artifacts/independent-v4-prepared-20260828/。该批按事件排除了59个历史开发事件，冻结10个事件/200篇新闻；正文和URL去重不保证现实事实独立，也不能排除模型历史回测的未来知识。

当前限制：只能选择本地归档可用的事件，不联网创建新市场；官方结算评价通过已实现CLI执行后在网页展示，尚无网页一键评分按钮。复杂复合问题、泛化的事件参与方关系及语义事实归并仍需后续改进。


2026-10-23 更新：新冻结任务使用 typed_v5；历史任务按其保存策略解释。V5 证据详情显示关系、冲突阻断、模板限定条件和时间判断；这些是匹配解释，不是结算证明。新批次评分仍通过 CLI 生成，工作台加载已保存的评价。最新 18 事件报告见 matching-v5-summary.html。服务关闭后重新运行 run_web.py；不会自动重跑付费抽取。
