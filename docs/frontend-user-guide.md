# 时窗工作台使用说明
本地地址：http://127.0.0.1:8765/
项目目录：D:\27专利\事件预测动态检索窗口

## 启动
在 PowerShell 中执行：
```powershell
Set-Location 'D:\27专利\事件预测动态检索窗口'
$pythonExe = Join-Path $env:USERPROFILE '.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $pythonExe -B .\run_web.py
```
也可使用自己的 Python 3.11+。启动时要校验历史工件，当前目录约需十余秒。
看到 Local workbench 提示后打开上述地址。终端启动时按 Ctrl+C 停止服务。
默认端口被占用时可用 --port 8766；不要重复启动已运行的同端口服务。
前端由本地服务提供，请勿直接双击 web/index.html。
Python 仅使用标准库；ECharts 6.0.0 已随项目保存，无 CDN、无前端构建步骤。

## 从哪里开始
1. 任务中心搜索问题、市场 ID、批次，选择一份冻结运行。
2. 调度工作台拖动轮次滑块，查看窗口前后边界、概率、模拟预算和来源状态。
3. 点击图上的证据点或列表，右侧查看原文、有效匹配目标、五要素和准入原因。
4. 配置新运行可调整策略、预算和窗口；截止时间与语料保持冻结，输出保存为独立工件。
5. 运行记录显示实际完成轮次，可请求取消、下载已记录轮次、打开完成结果。
6. 实验对比先选择同组的三策略。输入、标注、任务、配置和代码版本不一致时，只显示并列浏览提示。
7. 已保存批次评价显示原报告协议与分母，不会把原评分自动移给新运行。

## 如何理解证据与图
- 已存预测证据：原结果中实际保存的准入证据。
- 诊断证据池：当前代码重新解释冻结输入。空心灰点表示所选轮尚未读取；空心金色点表示已读取但诊断未准入。
- 诊断点不进入已存概率，诊断无法校验时显示未知。
- 五要素表优先显示 matching_trace.target 中实际匹配目标；原始任务字段仍在展开详情中。
- 当前概率属于调整后窗口；损失率是调度前判据。回放控制只播放已存记录，不代表任务正在运行。
- 旧记录未保存每轮权重或逐格实际开销时，不推测补值；最终 weight 不能当所有轮的权重。
- 来源图每组显示最多 8 个来源；表格可独立滚动。
- 预算是检索模拟单位，不是人民币或 API token 数。

## 当前版本边界
网页同时提供冻结输入重跑与新事件选择、UTC截止时间、模型抽取、三策略运行；详见 fresh-workflow-user-guide.md。改变配置会创建新的冻结输入，不改写旧运行。
官方结算采集仍由已实现CLI执行，结果可在网页查看。
已有历史工件中，部分没有完整冻结正文或与当前抽取校验不兼容，可查看但不能重跑。
网页重跑采用当前引擎；历史版本精确复验仍由原验证脚本和归档源码完成。
取消保留已完成轮次的诊断轨迹；未生成完整结果时不能当成完成预测。
typed_v4 已覆盖部分实体、事件关系与时间匹配；泛化语义能力及预测质量提升仍须单独验证。

## 文件位置
- 界面：web/；本地服务：run_web.py、src/dynamic_retrieval/web_*.py。

- 队列、进度、日志、取消后轨迹：.runtime/web-jobs/<运行ID>/。
- 浏览器验收截图与浏览器测试配置：.runtime/browser-qa/。
- 原始归档 D:\agents-main\agents\polymarket\data 只读。
