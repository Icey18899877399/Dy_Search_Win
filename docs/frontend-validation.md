## 浏览器联调发现并修复
- Windows .mjs 默认 MIME 不正确，改为显式 JavaScript 类型。
- 脚本补丁插值导致初始化失败，改正后浏览器无错误。
- 来源长表撑高页面，改为限定高度和热图分组。
- 五要素表显示原始任务而非实际匹配目标，修正为优先 matching_trace.target。
- 自动三策略匹配跨消融组，修正为优先相同 group + market_id。
- Windows 进度快照写入竞争，采用有界原子替换重试。
