# 五要素匹配 v4：开发回归验收

本轮按计划完成版本化语义匹配修复、冻结输入对照及前端诊断展示。文件、缓存、历史备份和浏览器截图均在 D:\27专利\事件预测动态检索窗口；原始数据只读，新增模型调用 0。

## 实现范围

- typed_v4 独立启用；typed_v2 / typed_v3 及旧预测工件保留。
- 闭集主体别名，军事行为上下文中的国家/军队映射；不直接把部长、政党或联合主体等同国家。
- 同意/拒绝自身缴械、军事进展、文件解封公开、离职表态或压力分别记录事件关系；不将这些关系当成目标事件已经完成。
- 明确主体、客体、地点冲突，以及当前观察范围外的明确事件时间阻断准入；未知日期不补成发布日期。
- 时间暂采用预测年开始至冻结截止日，并结合 by/before/after/in 边界。这是保守的当前年背景策略，可能排除有用的往年背景；不是专利要求的通用时间逻辑。
- 比较视图可补充有依据的客体，但原始要素、支持向量、事实键、模型标注和全文保持不变。
- 前端四列显示目标、原始证据与匹配状态，并显示事件关系、阻断原因和时间判断。

24 条可通过匹配的文档中，1 条尚未读取；23 条已准入的文档中，5 条未保留到最终窗口。9 条未通过匹配的方向性文档仍需解决主体归属、复杂关系或保守规则覆盖问题。

这些数字来自开发数据回用，不能当独立测试成绩。此轮未计算新预测的 Brier 或准确率；概率脱离 0.5 不代表变准。
