# 专利预算口径修正（2026-10-23）

本次执行用户确认的顺序：修正预算与回收核算 → 针对性行为测试 → 少量已用数据回放。范围限定在现有引擎及调用入口，不扩充样本、不调整准入阈值或方向性标注。

## 对应专利条文

- [0103] 常规单轮基准 B = 总检索预算 / 计划轮数。
- [0108] 当轮有效预算 E = min(B, 轮初剩余 R)，降低频率不再把 E 改成守候消耗。
- [0108—0113] 分别预留探测 P、守候 W、回收 C；P+W+C≤E，W+C≤共享比例×R；常规检索用余额。
- [0104] 进入守候时锁定累计上限，只累计实际 W。探测、常规检索、回收不计入等待累计消耗；返回继续状态后该等待段结束。
- [0248—0249] 回收来源为活跃且空尽概率未达标的来源；C=Σ来源单位跨度成本×完整过渡带宽。预算准入、净收益扣减和实际回收记账使用同一 C。
- [0251—0252] 损失率达标、净收益非负且完整跨度可执行才回收，证据当轮更新，下一轮继承边界；冷却期不绕过。

## 接口与成本定义

`engine.run(..., budget_policy="patent_budget_v1")` 与 `run_on_demand(..., budget_policy="patent_budget_v1")` 显式启用；自动配套整带回收。CLI 的 `run` / `compare` 支持 `--budget-policy patent_budget_v1`。不传参数保留历史复现行为；旧实验文件不改写。旧 Config 的 round_budget 和 recovery_fraction 不参与新规则预算计算，输出诊断明确记录忽略情况。

回收来源成本解释为包含该跨度检索和读取的总预算当量，因此对回收阶段不重复叠加 query_cost/read_cost；完整可见回收跨度的正文会被读取，缓存不会重复调用模型。常规、守候和探测仍使用已有请求/读取当量计费。模型真实 usage、请求限制和费用账本保持独立，这些配置当量不等于真实人民币或美元支出。

先执行守候和探测，再依据已观测带外证据预留整带回收额度，常规检索使用剩余额度。预留不等于消耗，未支出的额度保留在总预算中。来源状态更新后对预留额度重新核对，只能挪用尚未花掉的常规额度。逐轮记录轮初 R、B、E、共享上限、各项预留和实际支出。

真实归档仅回放三个既有开发市场：1171663、1423716、2354063。选择依据为原焦点及既有市场编号排序前两项，在读取本次结果前固定。basic/enhanced 共6个新规则运行，并复现6份旧派生预算整带结果；不是独立评价。输入和代码哈希随运行保存。

## 保留的边界与优先级

1. 本次修正预算账本，不声称已完整实现专利全部实施例。增强网格仍沿用原有归一化总额分配，第[0205]段逐网格上限公式需下一步单独对齐。
2. 轮次时钟仍是截止时刻固定的归档模拟，尚未模拟新证据随时间到达。后续应先用已有多时点归档检验静默、补发、恢复与停止。
3. 成本和阈值仍是配置示例；SQLite查询耗时不得作为新闻来源接口成本标定。真实来源日志应对应接口时延、配额与返回体量，缺失值不伪造。
4. 阶段十四“106个事件全部暴露”仅表示当时保守策略将所有筛选排除都纳入登记。元数据筛选不等于读取正文、查看结算标签或用于调参；不能据此断言独立数据已用尽。历史登记保留，正式独立评价前须细分暴露类型。
5. 本次不修改可视化工作台默认调度入口；新规则可通过明确的Python/CLI入口和本次回放脚本执行。前端接入时必须展示所用规则及成本口径。

## 本次验证结果

351项Python回归通过，其中11项新预算行为测试；一次独立只读代码审查发现并修复来源集合变更后的旧预留误拒绝。针对该缺陷先观察到失败，再验证修复通过。测试日志：`patent-budget-tests.txt`。

焦点2354063的basic第7轮、enhanced第8轮首次观测到损失1、损失率1。当前18个符合回收条件的来源均使用未标定的0.05预算当量/天，完整14天回收需18×0.05×14=12.6；常规单轮基准仅200/24≈8.333。即使不预留探测和守候，整带成本也超过整轮预算。实际预留探测2.083、守候3.333后，回收容量约2.917，因此拒绝有明确数值依据。

这个结果排除了“只要放开25%回收比例就一定扩窗”的误判，也指出当前逐来源默认成本与总预算尺度需要检查。下一步应核对[0249]归一化成本的基准尺度、来源集合和预算可行性，并对齐[0205]网格预算公式；不要直接放大预算或降低成本以制造成功。然后再以已有多时点数据验证证据到达过程。

这里读取增加不代表准入正确或预测准确率提升；六个真实回放均未整带回收，也未新增最终方向证据。正向回收、零收益边界和来源变化后可回收的证明来自明确标记的合成行为测试。模型请求0；真实接口成本标定和独立评价不作为本次已完成事项。
