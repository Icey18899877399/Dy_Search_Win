1. 引擎可选 decision_trace=True，记录决策前窗口当量、过渡带逐条贡献、来源资格、预算限额、候选跨度/净收益、拒绝原因和决策后证据去向。关闭时完全保留原输出。
2. runtime_policy 显式配置证据跨度样本来源、任务时限及紧迫度/剩余预算参数表。逐轮查表更新 slow_multiplier / waiting_share / shared_quota；slow_fraction 仍为固定档位。记录输入、插值坐标、参数和进入守候时锁定额度。严禁用发表间隔冒充证据酝酿期；无配置沿用旧路径。
3. 参数模块补原文 [0249] 来源指标归一折算和基于历史同类事件时刻的酝酿期分位工具。真实数据不足时不伪造标定结果。
4. 冻结18事件进行基线一致性、焦点事件逐轮解释、单参数窗口/预算/来源成本对照，以及明确标为演示的紧迫度表联调。另存结果，不调标签、不修改旧策略。
5. 保留工程部分跨度回收实现，报告与专利全过渡带回收的区别；本轮先保证每个判据可解释且参数调整确实接入，不以一定改变预测为验收。
