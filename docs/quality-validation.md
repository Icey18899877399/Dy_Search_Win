## 真值接入规则

不使用 outcomePrices、proposed_price、price 或本地价格代理作为结算标签。必须核对市场 ID、条件 ID、题目/结算描述和事件归属；只接受 resolved 状态下的二元终局支付向量、晚于预测截止且不晚于获取时点的结算时刻，以及交易哈希或结算区块依据。支付值允许整数比例（如 0/1000000），只在恰好一个结果有正支付时映射 Yes/No；平分支付和无明细记录不评分。非最终争议状态也不评分。

这里核验的是官方 API 提供的记录，不声称独立重放区块链交易。单市场响应不包含事件时，另外查询官方事件并核对其中的市场及条件 ID。

参考官方接口文档：
- https://docs.polymarket.com/api-reference/markets/get-market-by-id
- https://docs.polymarket.com/api-reference/events/get-event-by-id
- https://docs.polymarket.com/api-reference/markets/get-resolution-state

## 运行

在项目根目录执行：

    python -B run_quality.py --output artifacts/new-quality-offline
    python -B run_quality.py --fetch-official --output artifacts/new-quality-official
    python -B scripts/verify_artifacts.py

输出必须新建或为空；不带 fetch-official 时只生成覆盖诊断和冻结评价配置，不访问网络，官方指标为空。已保存结果可通过验证器离线重算检查。
