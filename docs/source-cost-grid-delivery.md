# 来源成本与网格预算交付（2026-10-23）

本轮完成专利[0249]来源成本配置接入、[0205]逐格预算对齐及冻结重跑前端。全部开发、日志、示例与工件位于D盘；原始数据只读。新增模型请求0。完成的是实现与可复核验证，真实参数标定和独立质量评价尚未完成。

## 完成内容

- 来源成本接口接收完整可见来源集合的三指标观测：响应时延、额度、返回条数，并要求接口标识、出处、同口径观察窗口、单位和不晚于预测截止的带时区观测时间。按专利加权归一化，不反转额度项，不对当前启用子集重新归一化。拒绝缺字段、缺来源、重复来源、混合测量类型、零成本、非有限数值及未来观测，不静默回退默认值。
- 配置原文及SHA256随结果保存。明确区分 synthetic 与 supplied interface observations；后者只说明提供了接口观测，系统未验证其真实性，不能据此宣称完整经验标定或真实账单成本。
- 增强网格按 `b_i=B×cap_fraction×exp(-decay×distance/nominal_band_width)` 逐格分配，B=总预算/计划轮数。格宽是名义带宽比例；从早端切格，不能整除的余格位于近边界。无总额归一化、无跨轮信用。资源组合不兼容时明确拒绝；末轮余款不足则整格跳过，不缩放公式。归档截断不改写名义带宽。
- 修复审查发现的日期浮点累加微格问题：按相对坐标及整数索引切格，避免额外近零宽格领取预算。对日期平移、非整除、1000格边界建立回归。
- Python、按需抽取、CLI、冻结回放API与前端已贯通。历史结果回填原规则；用户可明确启用新预算、选择专利网格或沿用原网格。新事件模型抽取页面本轮未迁移到新规则。

## 操作入口

打开 http://127.0.0.1:8765/ → 选择已有运行 → 配置新运行 → 规则选择“专利预算与网格” → 增强网格选项 → 可选粘贴/读取成本JSON → 启动离线重跑。历史结果默认保留历史规则；旧patent_budget-only结果默认沿用原网格。

`docs/examples/patent-grid-v1.json` 是显式示例网格配置；`docs/examples/source-cost-synthetic-demo.json` 仅适用于合成Aurora演示的来源集合，不是测量结果，不能用于真实事件冒充标定。

CLI的 run / compare 新增 `--grid-policy <JSON文件>`、`--source-cost-profile <JSON文件>`，须配合 `--budget-policy patent_budget_v1`。compare中网格仅作用于enhanced；所有模式可用同一来源成本配置。API的execution对象与Config分离，不接受服务器文件路径。Python参数同名：grid_policy、source_cost_profile；默认不传入时保持历史行为。

## 下一步与明确门槛

1. **先统一并实测预算单位和最小可执行成本。** 当前B=200/24、格上限比例0.2、宽度比例0.25时，四格预算约1.471、1.145、0.892、0.695，而查询0.2+新正文读取1.0=1.2。后三格不能独立读入新正文。固定四格、守候份额0.4时，要让最远格读一篇需上限比例至少约0.345，但容纳所有格及守候的上限约0.238，两者无交集。这是解析约束，不是调参搜索结果，见source-cost-grid-feasibility.json。不能简单靠抬高格比例解决，也不应恢复跨轮信用来掩盖字面规则冲突。
2. 采集实际检索接口的可比延迟、配额、返回条数、观测窗口及出处，明确base_cost如何换算为同一预算单位；同时说明查询/读取成本与整带成本的关系。既有486次本地SQLite查询不替代发布者接口配额。权重、基础尺度和其它参数均未因本轮接口上线而得到实测标定。
3. 在少量已用开发事件上先验证每格可执行性、实际读取与边界外证据损失，再接入按observed_at推进的证据到达回放。当前仍是固定截止归档模拟时钟，不代表真实在线动态到达。
4. 完成以上门槛后再按暴露类型冻结未用于语义调试/调参的新事件，开展同预算独立评价。此前元数据筛选排除登记不等同于所有事件都已参与语义开发；也不能直接将其全部解除排除。

本轮未改默认参数、未建立独立质量收益、未验证真实模型费用节省。核验摘要见source-cost-grid-verification.json。
