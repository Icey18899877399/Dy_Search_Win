# 逐条来源缺口核查与正文恢复（2026-10-23）

本轮解决了一个实际的正文覆盖缺口：最新记录退化为网页存档提示时，可以找到截止前的完整历史正文，并输出带原始时间、哈希和连续文本窗口的诊断候选。**可靠事件日期与合规计数来源仍未闭合，尚不具备推进标定或独立评价的证据条件。**

## 四类缺口如何继续处理

1. **事件日期：仍需来源绑定。** 俄乌报道中的4月11—12日是停火生效区间，不能直接当作正式协议达成日期；部分正文有完整日期的作者/更新时间栏，也不能直接替代事件时间。应只增加具有明确语义指向和原文锚点的日期解析规则，并用真实反例验证图片日期、旧事件和生效时间不会串用。
2. **任务条件：全文已保留，语义实现仍不完整。** 停火任务需要正式、公开、双方同意、一般军事行动范围及排除项，政治框架另需明确停止作战日期；议会需区分初读进展与正式解散。计数任务还规定主信息流回复例外、被捕获的删除帖、社区转发以及计数器异常时的备用来源。现有关键词见证不能替代这些逐条约束，更不能仅凭计数器名称放行。
3. **正确计数来源：当前检索范围没有补到。** 需要截止前可见的指定Post Counter快照/导出，或满足任务备用条件的可重建原始帖子记录。必须记录时间区间、时区、计数口径和来源状态。冻结截止仍为4月30日23:59:59 UTC，不能把截止后取得的整月总数当作当时已知证据，也不能悄悄后移截止。
4. **抽取覆盖：把输入可见与语义正确分开。** 事实窗口已包含这7篇案例的12段既有证据段；继续重复同样抽取并不能补出原文不存在的日期或计数。下一轮应先完善上述字段及有限规则的开发正反例，再对确有新增有效信息的窗口做有界抽取验证。

专利[0036]的任务相容规则和[0058]的方向支持须建立在可比较事态上；本轮不通过复制任务日期、改写初读为解散或临时降低准入阈值来制造支持。先补数据及语义条件，再采集真实标定观测；冻结后才进入独立事件评价。
